## Соглашения

- **Базовый URL:** `https://<host>/api/v1`, админка — `https://<host>/api/v1/admin`.
- **Формат:** JSON UTF-8. Даты и время — ISO 8601 в UTC (`2026-11-13T10:15:30Z`).
- **Идентификаторы:** UUID в строковом виде.
- **Деньги:** десятичные числа, по умолчанию валюта `RUB`.
- **Аутентификация:** `Authorization: Bearer <access_token>`.
- **Ошибки:** единый конверт `{"error": {"code", "message", "details"}}`.
- **Пагинация:** `page` (с 1) и `per_page` (1–100), ответ — объект `Page`.

## Поддержка

Перед обращением в поддержку соберите:

1. время и часовой пояс инцидента;
2. `X-Request-ID`, если он прокидывается reverse proxy;
3. метод, путь и тело запроса **без секретов**;
4. HTTP-статус и `error.code`;
5. результат `/health` и `/ready`.

Не отправляйте в поддержку `SECRET_KEY`, `TELEGRAM_BOT_TOKEN`, refresh-токены,
TOTP-секреты и персональные данные пользователей.
