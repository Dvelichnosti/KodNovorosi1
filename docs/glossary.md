# Глоссарий

Термины, статусы, перечисления и коды, используемые в BizBoard.

## 1. Общие термины

| Термин | Значение |
|---|---|
| **BizBoard** | Платформа B2B-объявлений для малого и среднего бизнеса |
| **MVP** | Минимально жизнеспособная версия: без платежей, чата и мобильного приложения |
| **API** | HTTP-интерфейс, через который клиенты работают с платформой |
| **OpenAPI** | Машиночитаемое описание API (`/openapi.json`) |
| **Backend** | Серверная часть: этот репозиторий |
| **Модерация** | Ручная проверка объявлений, документов и жалоб |
| **SLA** | Соглашение о сроке реакции; для модерации — 24–48 часов |
| **p95** | 95-й процентиль задержки; цель поиска — < 300 мс на 50 000 объявлений |
| **Soft delete** | Мягкое удаление: запись остаётся в БД с `deleted_at` |
| **Seed** | Идемпотентное заполнение справочников и системных записей |
| **Audit log** | Журнал действий администраторов |
| **Rate limit** | Ограничение частоты запросов |
| **Idempotent** | Повторное выполнение не создаёт дубль и не меняет результат |
| **UTC** | Всемирное координированное время; все даты в API в UTC |
| **UUID** | Универсальный уникальный идентификатор |
| **JSONB** | Бинарный JSON в PostgreSQL с индексацией |
| **GIN** | Индекс PostgreSQL для полнотекстового поиска и JSONB |
| **FTS** | Full-Text Search, полнотекстовый поиск |
| **tsvector** | Представление текста для полнотекстового поиска PostgreSQL |
| **RBAC** | Ролевая модель доступа: роли → права |
| **JWT** | JSON Web Token, подписанный токен доступа |
| **TOTP** | Time-based One-Time Password, код из приложения-аутентификатора |
| **MFA** | Многофакторная аутентификация; здесь — TOTP |
| **Deep link** | Ссылка `t.me/...?start=...`, открывающая бота с параметром |
| **Webhook** | HTTP-вызов от Telegram к API при событии |
| **Fernet** | Симметричное шифрование, используется для TOTP-секретов |
| **SHA-256** | Криптографический хеш; хранится вместо токенов |
| **Access token** | Короткоживущий токен доступа (15 минут) |
| **Refresh token** | Долгоживущий токен обновления (30 дней) |
| **Token family** | Цепочка ротаций refresh-токена; при компрометации отзывается целиком |
| **Claim** | Поле внутри JWT (`sub`, `exp`, `mfa` и т. д.) |
| **ИНН** | Идентификационный номер налогоплательщика: 10 цифр у юрлица, 12 у ИП и самозанятого |
| **ОГРН** | Основной государственный регистрационный номер |
| **ЕГРЮЛ** | Реестр юридических лиц |
| **ЕГРИП** | Реестр индивидуальных предпринимателей |
| **Самозанятый** | Плательщик налога на профессиональный доход |
| **ДНР** | Донецкая Народная Республика |
| **ЛНР** | Луганская Народная Республика |
| **Херсонская область** | Регион присутствия платформы |
| **Запорожская область** | Регион присутствия платформы |

## 2. Роли

### 2.1. Платформенные роли

| Код | Назначение |
|---|---|
| `superadmin` | Полный доступ ко всем платформенным правам |
| `moderator` | Модерация объявлений, жалоб, организаций, каталога |
| `support` | Просмотр пользователей, верификация, жалобы |

Роли создаются при seed и могут дополняться кастомными ролями.

### 2.2. Организационные роли

| Роль при создании организации | Права |
|---|---|
| Владелец | Все права организации |
| Менеджер объявлений | Создание, редактирование, публикация, удаление, статистика, продвижение, ответы на отзывы |
| Редактор профиля | Профиль, контакты, ответы на отзывы |
| Только просмотр | Статистика и тариф |

Владелец определяется флагом `org_members.is_owner=true`, а не записью роли.

## 5. Статусы и перечисления

### 5.1. Пользователь (`UserStatus`)

| Значение | Значение |
|---|---|
| `active` | Активен |
| `blocked` | Заблокирован |

### 5.2. Тип организации (`OrgType`)

| Значение | Значение |
|---|---|
| `legal_entity` | Юридическое лицо |
| `sole_proprietor` | Индивидуальный предприниматель |
| `self_employed` | Самозанятый |

### 5.3. Статус организации (`OrgStatus`)

| Значение | Значение |
|---|---|
| `active` | Активна |
| `blocked` | Заблокирована |

### 5.4. Уровень верификации (`VerificationLevel`)

| Значение | Значение |
|---|---|
| `none` | Без верификации |
| `phone` | Телефон подтверждён |
| `inn` | ИНН проверен |
| `moderator` | Проверен модератором |

Уровни повышаются последовательно; `moderator` — максимальный.

### 5.5. Участник организации (`MemberStatus`)

| Значение | Значение |
|---|---|
| `active` | Активный сотрудник |
| `removed` | Удалён из организации |

### 5.6. Приглашение (`InvitationStatus`)

| Значение | Значение |
|---|---|
| `pending` | Ожидает принятия |
| `accepted` | Принято |
| `revoked` | Отозвано |
| `expired` | Истекло |

Срок жизни — `INVITATION_TTL_HOURS` (72 часа).

### 5.7. Документ (`DocumentKind`, `DocumentStatus`)

Типы:

| Значение | Значение |
|---|---|
| `egrul` | Выписка ЕГРЮЛ |
| `egrip` | Выписка ЕГРИП |
| `self_employed` | Справка самозанятого |
| `other` | Другой документ |

Статусы:

| Значение | Значение |
|---|---|
| `pending` | На проверке |
| `approved` | Одобрен |
| `rejected` | Отклонён |

### 5.8. Тип объявления (`ListingType`)

| Значение | Значение |
|---|---|
| `sale` | Продам |
| `rent_out` | Сдам |
| `wanted_buy` | Куплю |
| `wanted_rent` | Сниму |
| `service_offer` | Оказываю услуги |
| `service_wanted` | Ищу подрядчика |
| `tender` | Тендер |
| `partnership` | Партнёрство, франшиза |

### 5.9. Статус объявления (`ListingStatus`)

| Значение | Значение |
|---|---|
| `draft` | Черновик |
| `pending` | На модерации |
| `active` | Активно |
| `rejected` | Отклонено |
| `archived` | В архиве |
| `expired` | Истекло |
| `blocked` | Заблокировано |

Переходы:

```text
draft ──submit──▶ pending ──approve──▶ active ──expire──▶ expired
  ▲                  │                    │
  │                  └──reject──▶ rejected│
  │                                      ├──archive──▶ archived
  └──────────edit rejected───────────────┘
                     active ──edit──▶ pending
                     active ──block──▶ blocked
```

### 5.10. Продвижение (`PromotionType`)

| Значение | Значение |
|---|---|
| `top` | Приоритет в выдаче |
| `highlight` | Визуальное выделение |

### 5.11. Жалоба (`ComplaintStatus`)

| Значение | Значение |
|---|---|
| `new` | Новая |
| `in_review` | В работе |
| `resolved` | Решена |
| `rejected` | Отклонена |

Причины жалоб:

| Значение | Значение |
|---|---|
| `spam` | Спам или дубль |
| `fraud` | Мошенничество |
| `wrong_category` | Неверная категория |
| `prohibited` | Запрещённый товар или услуга |
| `offensive` | Оскорбительный контент |
| `other` | Другое |

### 5.12. Тип атрибута (`AttributeType`)

| Значение | Значение |
|---|---|
| `string` | Строка |
| `number` | Число |
| `enum` | Один вариант из списка |
| `multi_enum` | Несколько вариантов |
| `bool` | Да/Нет |
| `range` | Диапазон |
| `date` | Дата |

### 5.13. Регион (`Region`)

| Значение | Значение |
|---|---|
| `dnr` | ДНР |
| `lnr` | ЛНР |
| `kherson` | Херсонская область |

### 5.14. Сессия входа (`LoginStatus`)

## 7. Тарифы

| Код | Название | Лимит активных | Цена |
|---|---|---|---|
| `free` | Бесплатный | 10 | 0 |
| `business` | Бизнес | 50 | 2990 |
| `pro` | Про | 200 | 7990 |

Частное лицо без организации — лимит `PRIVATE_ACTIVE_LISTING_LIMIT` (3).
Тарифы и продвижение в MVP назначает администратор вручную.

## 8. Коды ошибок

Полный каталог — в [api.md](api.md#11-коды-ошибок). Часто встречающиеся:

| Код | HTTP | Значение |
|---|---|---|
| `unauthorized` | 401 | Нет токена |
| `invalid_token` | 401 | Токен не декодируется |
| `token_expired` | 401 | Access-токен истёк |
| `refresh_reuse_detected` | 401 | Повторное использование refresh-токена |
| `account_blocked` | 403 | Пользователь заблокирован |
| `mfa_required` | 403 | Нужен TOTP |
| `permission_denied` | 403 | Нет права |
| `not_org_member` | 403 | Нет участия в организации |
| `permission_escalation` | 403 | Нельзя выдать больше прав, чем есть |
| `listing_limit_reached` | 403 | Достигнут лимит публикаций |
| `validation_error` | 422 | Ошибка схемы |
| `category_depth_exceeded` | 422 | Больше 3 уровней каталога |
| `invalid_inn` | 422 | Неверная контрольная сумма ИНН |
| `rate_limited` | 429 | Превышен лимит запросов |
| `internal_error` | 500 | Внутренняя ошибка |
